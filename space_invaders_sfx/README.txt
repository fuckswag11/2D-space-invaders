Space Invaders original chiptune sound effects, generated for this tutorial.

Copy the assets folder into the ROOT of your 2D-space-invaders project.
Expected paths, relative to the project root:
  assets/sfx/shoot.wav
  assets/sfx/enemy_shoot.wav
  assets/sfx/enemy_hit.wav
  assets/sfx/player_hit.wav
  assets/sfx/shield_hit.wav
  assets/sfx/ufo_hit.wav
  assets/sfx/win.wav
  assets/sfx/lose.wav

Run the game while the terminal's current directory is the project root.
All audio here is original and generated for this lesson, not extracted from any game.
